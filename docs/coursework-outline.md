# План курсовой работы по чек-листу методички

## Название

**«Проектирование интеллектуального сервиса для поиска музыкальных композиций по текстовому описанию и эмоциональным характеристикам»**

Название курсовой аналогично теме ВКР и начинается со слова «Проектирование».

## Цель, объект и предмет

**Цель работы** — спроектировать интеллектуальный веб-сервис, который находит музыкальные композиции по смыслу текстового описания и эмоциональным характеристикам.

**Объект исследования** — процессы поиска и подбора музыкальных композиций в цифровом каталоге.

**Предмет исследования** — методы семантического поиска, анализа текстовых эмоций и ранжирования музыкальных композиций.

**Задачи работы:**

1. Рассмотреть предметную область и сформулировать требования к сервису.
2. Сопоставить методы поиска по ключевым словам и по смыслу текста.
3. Обосновать выбор моделей и программных технологий.
4. Спроектировать архитектуру, модули, API и структуру базы данных.
5. Описать обработку запроса, оценку эмоций и алгоритм ранжирования.
6. Определить набор данных и план экспериментальной оценки качества.

## Предлагаемая структура

1. Титульный лист.
2. Задание на курсовую работу.
3. Содержание — 1–2 страницы.

### Введение — 1–2 страницы

Актуальность темы, цель, задачи, объект и предмет проектирования, методы и структура работы.

### 1 Анализ предметной области

1.1 Особенности поиска музыкальных композиций по пользовательскому описанию.  
1.2 Музыкальные рекомендательные сервисы и способы поиска.  
1.3 Требования, пользовательские сценарии и ограничения проектируемого сервиса.

### 2 Анализ методов и технологий

2.1 Поиск по ключевым словам и семантический поиск.  
2.2 Векторные представления текста и модели Sentence Transformers.  
2.3 Анализ эмоциональных характеристик русскоязычного текста.  
2.4 Векторное хранилище pgvector и база данных PostgreSQL.  
2.5 Обоснование выбранного стека.

### 3 Проектирование сервиса

3.1 Архитектура модульного монолита.  
3.2 Состав модулей и ответственность компонентов.  
3.3 Сценарий обработки поискового запроса.  
3.4 Модель данных и структура базы данных.  
3.5 API и интерфейс пользователя.

### 4 Проектирование интеллектуального модуля

4.1 Подготовка текста запроса и описаний композиций.  
4.2 Получение эмбеддингов и отбор кандидатов.  
4.3 Определение эмоций запроса и эмоциональный профиль композиции.  
4.4 Объединение признаков и ранжирование результатов.  
4.5 План экспериментальной оценки и сравнения с лексическим поиском.

### Заключение — 1–2 страницы

Основные результаты проектирования, выполнение задач и перспективы реализации.

### Список использованных источников — 1–4 страницы

В тексте источники указываются в квадратных скобках, например `[1]`. Список оформляется по ГОСТ 7.1-2003 согласно переданному чек-листу.

### Приложение

Скриншоты слайдов презентации. Рекомендуемый объём презентации — около 10 слайдов.

## Требования к оформлению из чек-листа

| Параметр | Требование |
|---|---|
| Шрифт основного текста | Times New Roman, 14 пт |
| Межстрочный интервал | 1,5 |
| Выравнивание | По ширине |
| Абзацный отступ | 1,25 см |
| Поля | Слева 30 мм, справа 10 мм, сверху и снизу по 20 мм |
| Номер страницы | Внизу по центру, 11 пт |
| Заголовки | По центру, полужирным начертанием |
| Раздел верхнего уровня | Начинать с новой страницы |
| Изложение | От третьего лица |
| Ссылки на источники | В квадратных скобках, например `[1]` |
| Подпись рисунка | Под рисунком; рисунок упоминается в тексте |
| Заголовок таблицы | Над таблицей; таблица упоминается в тексте |

## Рекомендации для презентации на 10 слайдов

1. Тема и автор работы.
2. Актуальность и проблема поиска музыки по свободному описанию.
3. Цель, задачи, объект и предмет.
4. Сценарии пользователя и требования к сервису.
5. Архитектура Moodify.
6. Структура каталога и база данных.
7. Семантический поиск и эмоциональный анализ.
8. Формула ранжирования результатов.
9. Макет интерфейса и демонстрационный сценарий.
10. План оценки качества и выводы.

## Правило академического изложения

Основной текст формулируется от третьего лица. Например: «В проектируемой системе запрос преобразуется в векторное представление, после чего выполняется поиск ближайших описаний композиций». Формы от первого лица («я разработал», «мы выбрали») в тексте курсовой не используются.
